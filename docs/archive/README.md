# Archived working notes

Historical working documents, kept because this project deliberately does not
delete superseded reasoning (`docs/GENERALIZATION-PLAN.md`, Phase 0): history
you can diff beats history you have to take on faith. Nothing here is current
guidance, and nothing here gates anything.

- `SPRINT-STEP-1.md`, `SPRINT-STEP-2.md`, `SPRINT-STEP-5.md` — step-scoped
  instructions written for the AI coding agent that worked the North Dumfries
  evidence sprint after the director review (`DIRECTOR-REVIEW.md`). They are
  addressed to that agent, not to a contributor; Step 2 exists in corrected
  form because its first version was wrong, which is exactly why these are
  retained. No Step 3 or Step 4 file ever existed in this repository's
  history; the numbering gap is original, not a deletion.
- `FLEET-DRY-RUN.md` — the maintainer's talk track for explaining the first
  FIR fleet dry run. A snapshot of how the project was being explained at that
  moment, not documentation of how it works now; for the current pipeline see
  `docs/ONTARIO-COMPLETION.md` and `docs/PROVINCIAL-ROLLOUT.md`.

For live contributor documentation, start at the repository `README.md` and
`CONTRIBUTING.md`.
