# Corrections log

Every reported figure that turned out to be wrong — and every report that
turned out to be right after all — is recorded here with a date, whatever the
outcome. `PURPOSE.md` commits this project to publishing its error rate: a
corrections log with dates is the only form of "trust us" this project is
allowed to use.

Report a suspected wrong number with the
[**Report a wrong number**](https://github.com/Jstn-1g/what-in-the-tax/issues/new?template=wrong-number.yml)
issue form. You do not need to be certain to file one.

## Format

Each entry, newest first:

```
## YYYY-MM-DD — <municipality or artifact> — <one-line summary>
- Reported: <issue link>  Status: confirmed | not-an-error | withheld
- What was published, what was correct, and how it got through the gates
- What changed so the same defect cannot recur (test, gate, or process), with
  the commit
```

A `not-an-error` outcome is logged too. A report that was checked and found
sound is evidence the instrument works, and the reporter deserves to see the
check happen.
